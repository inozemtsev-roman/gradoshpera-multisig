# Changelog

Все заметные изменения «Мультикошелька ДАО Градосфера» (multisig.gradosphera.org).

Формат основан на [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/),
проект придерживается [Semantic Versioning](https://semver.org/lang/ru/).

## [1.0.0] - 2026-08-05

### Добавлено

- **Стартовый экран с карточками мультикошельков ДАО**
  - Реестр мультикошельков ДАО (`multisigs.json`): добавлен **ДАО Градосфера** и его жетон **Благо** (адрес, decimals, логотип).
  - Карточки ДАО рядом с вашими открытыми мультикошельками, разделитель «Ваши мультикошельки:».
  - Мгновенный рендеринг карточек из синхронного снапшота реестра — без «Загрузка…»; балансы и статусы подтягиваются по сети.
  - Дизайн карточек по мотивам blago-vote: аватар 80×80, название, адрес, балансы внизу; адаптивная сетка 4→3→2→1 колонки.
  - Кнопка «Создать новый мультикошелек» перенесена в блок карточек (пунктирная карточка).
  - Баланс жетона Благо через tonapi даже для неразвёрнутого jetton-кошелька (корректный нулевой баланс).
- **Прокси для обхода блокировок TON API**
  - Cloudflare Worker и Vercel serverless-функция (единый маршрут `?url=<upstream>`).
  - Разрешены только whitelist-хосты; API-ключ хранится серверно и не виден в браузере.
  - Прокси включён по умолчанию (Vercel), задаётся также через `localStorage.proxy_url`.
- **Тёмная тема** на CSS-переменных; длинные адреса переносятся по словам.
- **Сокращённые адреса** в ссылках (`EQAbRLlm…h5K3n9`) с полным адресом в подсказке.
- **Дата истечения заявки** в русском формате: `31.08.2026 17:03:45 UTC (+10)`, для просроченных — «❌ ИСТЁК — 4 сентября 2026 года».
- CNAME `multisig.gradosphera.org` для GitHub Pages.

### Изменено

- **Полная русская локализация** интерфейса, сообщений об ошибках и README.
- **Tonviewer** вместо tonscan в ссылках на адреса и транзакции.
- **Страница мультикошелька**: адрес мультикошелька оформлен карточкой в стиле карточек главной страницы — аватар (логотип жетона сообщества или GRAM), название, адрес и балансы **GRAM** и жетона сообщества (например, **Благо**).
- **Линейная диаграмма порога** на странице мультикошелька в поле «Порог»: длинный прямоугольник со скруглёнными краями в стиле карточки адреса — левая половина (порог, синий) и правая (число подтверждающих, зелёный) с одинаковой прозрачностью; внутри каждой половины крупным жирным шрифтом — количество из порога.
- **Список заявок** на странице мультикошелька показывается постранично — 10 заявок с кнопками «Далее»/«Назад».
- **Снижение нагрузки на API**: детали заявок (get-методы и трассы исполнения) запрашиваются только для последних 10 заявок, трассы кэшируются — заметно меньше запросов и rate limit.
- **Мульти-провайдер с автофейловером**: toncenter → tonapi; кэш ответов, cooldown после сбоя, таймауты с понятным сообщением.
- Обновлён manifest TON Connect: название «ДАО Градосфера | Мультикошелек», корректный логотип.

### Исправлено

- **Ошибка «Invalid magic»** при разборе входящих сообщений (текстовые комментарии и сообщения в не-BOC формате больше не ломают страницу мультикошелька).
- **Сброс страницы мультикошелька** при сбоях загрузки списка заявок (rate limit, ошибки API): страница продолжает показывать конфигурацию мультикошелька без списка заявок.
- Совместимость с tonapi: корректная передача аргументов get-method (строки TVMStackValue), ячейки в hex, тип `num`, отрицательные числа.
- Endpoint транзакций tonapi; проверки трасс переведены на toncenter.
- Санитизация комментариев в заявках (защита от stored-XSS).
- Битый URL логотипа в manifest TON Connect.
- Таймауты запросов к API с понятным пользователю сообщением об ошибке.
